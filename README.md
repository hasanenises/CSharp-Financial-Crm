# Financial CRM

A desktop personal finance and CRM-style management application built with **C#**, **Windows Forms**, **Entity Framework**, and **SQL Server**.

## Features & Modules

- **Dashboard:** Overview of key financial indicators and summaries.
- **Category:** Create, read, update, and delete spending categories.
- **Expenses (`Spendings`):** Manage expenses linked to categories, amounts, and dates.
- **Bank Processes:** Record bank transactions (`Gelen Havale`, `Giden Havale`, `Yatırma`, `Çekme`) and automatically update bank balances (`BankBalance`).
- **Banks & Bills:** Manage bank accounts and recurring bills.
- **Settings (`Users`):** Manage application users.
- **Navigation (`FormLink`):** Centralized form navigation and logout confirmation.

## Tech Stack

- **Language:** C# (.NET Framework / Windows Forms)
- **ORM:** Entity Framework
- **Database:** Microsoft SQL Server (`.SQLEXPRESS` / Local instance)
- **IDE:** Visual Studio
